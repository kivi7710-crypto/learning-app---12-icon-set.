# learning-app---12-icon-set.
A aesthetic beginner friendly pastel coloured 12 icon set
Learning App - Icon Set

Project Overview

This project contains a collection of 12 consistent icons designed for a Learning Management App as part of my UI/UX Design Internship.

Objective

To create a simple and visually consistent icon library using a 24 × 24 px grid and export all icons in SVG format.

Icons Included

1. Home
2. Courses
3. Lessons
4. Notes
5. Assignments
6. Quiz
7. Calendar
8. Progress
9. Certificate
10. Bookmark
11. Profile
12. Settings

Design Specifications

- Grid size: 24 × 24 px
- Stroke width: 2 px
- Style: Minimal outline icons
- Stroke color: #333333
- Format: SVG

Tools Used

- Figma
- Figma AI

Project Structure

- "icons/" - Contains 12 exported SVG icons.
- "preview.png" - Complete icon set preview.
- "README.md" - Project documentation.

What I Learned

- Creating icons using a consistent grid.
- Maintaining uniform stroke width and alignment.
- Organizing editable vector layers in Figma.
- Exporting individual icons in SVG format.

Conclusion

This project helped me understand the importance of consistency, simplicity and scalability in UI icon design.
